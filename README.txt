# TheGuyBro YouTube-Style Prank Mockup

This is a standalone, fictional YouTube-style mockup for a harmless prank/demo.

- `index.html` = home page
- Click the profile picture in the top-right to open `channel.html`
- Channel is named **TheGuyBro**
- Shows **1,000,000 subscribers**
- The uploaded image is used as the profile picture
- Video thumbnails are intentionally non-playable
- No login, payments, tracking, or real YouTube account access is included

Open `index.html` in a browser to run it.
